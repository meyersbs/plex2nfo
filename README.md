# plex2nfo

This command line tool grew out of frustration. I wanted to migrate from Plex to Jellyfin, but I had meticulously edited episode metadata in Plex for shows that like to be special (e.g. Doctor Who (2005), Batman: The Animated Series). I didn't want to manually do all that again, but all of the tools that existed to generate nfo files for Plex either (1) only worked with movies, or (2) were AI vibe-coded garbage. **So, I wrote this from scratch to facilitate my migration.**

**ABSOLUTELY NO AI WAS USED TO WRITE THIS TOOL**
